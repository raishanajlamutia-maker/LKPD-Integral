# Integral Detective – LKPD Digital (Integral Tak Tentu, SMA Kelas XI)

## Cara menjalankan
1. Buka folder `Integral_Detective_LKPD` di VS Code.
2. Install extension **Live Server** (Ritwick Dey).
3. Klik kanan `index.html`.
4. Pilih **Open with Live Server**.
5. Website terbuka di browser.

Butuh koneksi internet untuk MathJax dan Google Fonts (CDN).

## Catatan
- Jawaban tersimpan otomatis di `localStorage`. Tombol **Mulai Ulang** menghapusnya.
- `assets/rumus_integral.png` dapat diganti dengan gambar rumus milik Anda (nama file sama).
- Tombol **Cetak Hasil** ada di halaman Hasil.
